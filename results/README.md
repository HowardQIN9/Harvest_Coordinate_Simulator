# Results directory

`results/current/` may contain outputs from more than one model revision. Directory names containing `harvest14h_rest10h`, `forecast12h`, a receiving pit, one semi, or the policies `sequential/reactive/adaptive` were generated by the superseded design and must not be treated as results from the current experiment.

## Current commands

Run one policy with complete time-series and event outputs:

```bash
python run_baseline.py --policy fixed
python run_baseline.py --policy threshold
python run_baseline.py --policy reactive
python run_baseline.py --policy predictive
```

Run a paired four-policy comparison:

```bash
python run_experiments.py
```

Run the 11-scenario preliminary mechanism set:

```bash
python run_experiments.py --mechanism
```

The mechanism summary is written to:

```text
results/current/mechanism/mechanism_summary.csv
```

Run the separate joint-capacity map:

```bash
python run_experiments.py --joint-capacity-mechanism
```

This scales the dryer curve, grain leg, and nominal direct-unload service
together. It preserves the dryer-only outputs and stores full traces for all
four policies under `current/joint_capacity_mechanism/`. See
`current/joint_capacity_mechanism/RUN_RECORD.md` for the exact design, results,
validation counts, and limitations.

Current scenario directories encode the field count, seed, moisture range, wet-bin and grain-leg capacity, semi count, shared order rule, work-before-STOP, minimum STOP, and prediction horizon.

## Interpretation status

Outputs generated before the actual planting order and dryer behavior are verified are **preliminary exploratory results**. They are intended to locate weak, intermediate, and severe downstream-constraint regimes, not to support a final percentage-improvement claim.

## Archive

`results/archive/` is retained for historical traceability and is not generated by the current runners. No historical result should be mixed into a current paired comparison.
